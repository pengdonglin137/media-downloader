# 显式源文修订的双版本媒体

`media_workflow.source_corrected_media`接续已验证的来源感知字幕与完整复合旁白。旧`editorial_media`仍承诺复制英文字幕流，不能用于本轮改词；新适配器明确重封装正文及母版的英文软字幕，视频和完整正文原声音轨仍逐包保留。冻结根Python、成功共享模块与成功试读不改。

```bash
PY=/vol_1t/pyvideotrans/.venv/bin/python
$PY -m media_workflow.source_corrected_media run CONFIG.json --output NEW_MEDIA
$PY -m media_workflow.source_corrected_media check CONFIG.json --output NEW_MEDIA
```

`prepare/encode/verify/check`也可分别执行。`run`仅准备不存在的工程，已有准备先核验；完整验证已经存在则直接check，不重复全片解码。每个实际命令复用冻结通用执行器的持久收据，失败、未收据输出或输入漂移均拒绝重启。输出锁在整个CLI操作中持有；工具观察超时不等于进程终止。

## 双层输入与真实生产者

- 外层配置精确包含`kind/scope/media_config/projection_config/projection_manifest`，类型为`source-corrected-complete-utterance-media-v1`，范围为隔离双版本、不安装。
- `media_config`是冻结共享准备模块的原格式，绑定当前音频质量、显式术语表及1至16编码线程。源文stage、字幕projection和quality必须逐项同源；新英文变更清单不得伪称英文不变。
- 共享准备器复制已审来源、译文、完整旁白与显示字幕，生成实际术语保护ASS、零尾界证明和一致性私库备份，再追加当前媒体工程扫描。其来源和旁白记录如实保留共享准备模块身份。
- 新`source-corrected-media.json`另绑定新生产者、全部实现、外层配置、原准备及新投影。最终包明确新生产者，不伪装冻结编码器；通用操作收据中的旧执行器身份仅表示谁实际运行命令，命令输入另绑定新生产者及完整新生产契约。
- 严格保护每个登记词，既有术语表要求非空`spoken_forms`。中文字面形式也应显式列入，不用空数组绕过模式。术语表不是本轮重新生成语音或发音批准的证据。

## 编码和有限授权

正文显式读取新的`en_display.srt`，母版显式读取新的完整`en.srt`，均用`mov_text`；不映射旧`0:s:1`，不声称英文编码包不变。中文及双语同样来自实际投影。中文旁白沿用原严格原窗和实际原声回填，保留原导读、章节、总时长、双音轨母版及单中文烧字上传版。

`runtime(work)`只为精确选定工程接入已验证旁白、原声规则适用性及新包验证，其他工程仍走冻结验证。先复核完整来源感知投影及上游质量；拒绝嵌套、外来分派，正常和异常退出均恢复。只有确认新生产者身份、当前输入、字幕及所有历史几何后，才允许冻结包验证器执行依赖检查，不提供任意`allow_implementation_change`旁路。

## 验证范围

- 正文/母版仅对原视频及完整原声AAC的载荷、精确有理PTS/DTS/时长/flags和流配置逐包比较。英文字幕明确不在复制流证明中。
- 实际从正文/母版分别抽出英文轨，全文逐句核对源文修订后投影，允许的容器舍入不超过2毫秒；保存提取SRT和真实命令收据。完整母版三种软字幕另由冻结媒体检查逐项验证。
- 母版与上传版中文AAC编码包和解码PCM一致，完整解码帧的精确呈现时间、时长、数量与尺寸一致；烧字改变像素，不宣称两版像素相等。
- 对全部本轮编辑和实际原声区按真实导读偏移做完整窗口AAC诊断；两版完整音视频解码后，再生成绑定实际`render_state.json`的质量与原生技术release。
- 已有检查只读核验实际证据与字幕提取结果，不重复成功编码或解码。图审、有限VLC及历史安装是额外独立证据，不能由自动扫描替代。

本适配器不把相关性、WordBoundary、技术release、图片或dummy音频当作人耳、专业发音、情感、角色、全片视觉、逐词声画或PotPlayer批准。媒体保持隐藏候选，须另走显式保留历史的安装事务；不发布、不扩播放列表、不增加交付外挂。

本轮真实配置/日志/失败及成功候选位于`request-cjiUXZh0ZCo-20261114/memory-storage-media-v1`。首次空字面术语数组导致准备出口1，旧表/旧配置/失败工程保留；第二版仅按既有模式填入中文词条的非空字面形式，不改生产模块、时窗、语音或验证容差。
