## 表达与专业词处理

- 保留完整句和技术条件，再设计平述/提问解释的对照，不把“更有感情”理解为喊叫、夸张惊叹或模仿讲者。反问后明确回答，再解释条件；是否自然仍需实际试听。
- `calloc` 与 `C alloc`、`nallocx` 与 `N alloc X`、`sdallocx` 与 `S D alloc X` 是候选读法，不是官方发音或音素指令。屏幕精确名称保持；不更新全局词典，不因生成成功自动采用分组读法。
- 三个近似接口按“只算尺寸 / 查询已有分配 / 尝试原地调整”建立对照，保留不分配、已有、原地及返回大小检查。带大小释放保留历史5.2.1版本、无返回值、原始请求下限、兼容参数上限及sizeof不足的限制。
- 统计解释不把“当前已分配”误说成历史累计申请；保留两个字节量、非零分母及近似性。重新核对同版主源后明确resident是含元数据等的**上界估计**，不是进程精确RSS，不能只笼统叫“驻留量”。

每对的完整显示和显式事实契约相同，但口播措辞、术语读法也同时变化。时长差不能单独归因于标点、语气或情感；词界文本覆盖也不能证明实际音素正确。后续试听重点是N/S/X和S D是否能区分、“尝试”与“成功”的对比、上下界是否连贯、问答停顿是否机械，以及解释是否保留版本/条件。
